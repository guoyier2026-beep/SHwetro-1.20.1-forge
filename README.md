## About This Project

This repository contains a Minecraft 1.20.1 compatibility port of the Shwetro mod.

The original project was distributed as a Minecraft mod. This repository contains modifications and adaptations made to support the target Minecraft version and modding environment.

Changes in this repository may include:

- Minecraft version compatibility updates;
- Mod loader and API compatibility adjustments;
- Build system updates;
